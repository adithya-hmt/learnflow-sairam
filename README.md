# LearnFlow

Android-first learning, campus social, and student-progress platform for Sri Sairam Engineering College.

```bash
npm install
cp .env.example apps/mobile/.env
npm run android
```

## Install the Android app

Download the latest APK from the [Releases](https://github.com/adithya-hmt/learnflow-sairam/releases) page, open it on an Android phone, and allow installation when Android asks. This is a native Android build; Expo Go is not required.

The app runs immediately in safe demo mode when Supabase variables are absent. See [docs/README.md](docs/README.md) for setup, permissions, security, testing, architecture, and roadmap.
